The Random Walk

A running notebook on the 1D random walk — from the plain unbiased walk and its √N scaling, to reflecting boundaries, entropy production, and thermalization.

This site collects the theory, simulations, and interactive figures behind an ongoing project studying random walks through the lens of statistical mechanics and information theory — starting from a thermal physics course assignment and growing from there. The code behind these figures lives in the 1D-Random-Walk-Simulation repository.
