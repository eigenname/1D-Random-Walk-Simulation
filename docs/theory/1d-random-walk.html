The Lore

1D Random Walk

Aka the "drunkard's walk", a 1D random walk is the simplest possible random walk: a pedestrian takes steps of fixed size in either direction.

The Brass Tacks

We can model the pedestrian as a particle and track their position as a stocastic process, where for simplicity, we assume the following: the walk starts at the origin $X_{_0} \equiv 0$ and each step taken is of unit step size $|\Delta X| \equiv 1$.
Then with this notation, the pedestrian's final position after $N$ steps is $X_{_N} \in \mathbb{Z}$.
Therefore, a single walk of $N$ total steps produces one trajectory $(X_{_0}, X_{_1}, \dots, X_{_N})$, where $\forall \ n \leq N \in \mathbb{N}, \ X_{_n} = X_{_{n-1}} + \Delta X_{_n}$ and each displacement $\Delta X_{_n} = \pm 1$ is sampled independently with $\text{Prob}(\Delta X_{_n} = +1) + \text{Prob}(\Delta X_{_n} = -1) \coloneqq 1$.

A single walk's trajectory, position vs. step.

Biases or Equality of Directions

Note that with our formalism so far, the probabilities (or the biases) associated with each displacement are still arbitrary.
Since the displacement itself is a Bernoulli process, $(\Delta X_{_1}, \dots, \Delta X_{_N}) \in \{+1, -1\}^N$, we state that the walk is biased if $\text{Prob}(\Delta X_{_n} = +1) \neq \text{Prob}(\Delta X_{_n} = -1)$, e.g. $\text{Prob}(\Delta X_{_n} = +1) > \text{Prob}(\Delta X_{_n} = -1) = 1 - \text{Prob}(\Delta X_{_n} = +1)$.
Otherwise the walk is unbiased, or has equiprobable displacements, i.e. $\text{Prob}(\Delta X_{_n} = +1) = \text{Prob}(\Delta X_{_n} = -1) \equiv 1/2$.

Final Remarks

This covers an introductory formalism for the 1D random walk. Though note this walk is unbounded — the pedestrian/particle can drift arbitrarily far in either direction — and that we have not distinguished the number of steps taken versus the time elapsed.
